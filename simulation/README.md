# Physical Simulation

This directory contains the physical modelling and simulation components of the railway pantograph digital twin.

The simulation models the dynamic behaviour of the pantograph and supports the generation of operating data under normal and faulty conditions.

Main components include:
- Pantograph dynamic modelling
- Normal operating condition simulation
- Structural crack simulation
- Pneumatic leakage simulation
- Mechanical and electrical signal generation
- MATLAB/Simulink models
