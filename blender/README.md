# Blender 3D Visualization

This directory contains the Blender components used for the 3D visualization of the railway pantograph digital twin.

The 3D environment provides a visual representation of the pantograph and its interaction with the overhead contact line.

Main components include:
- 3D pantograph visualization
- Pantograph animation
- Catenary representation
- Real-time geometry updates
- Python scripts for Blender
- Integration with digital twin data
